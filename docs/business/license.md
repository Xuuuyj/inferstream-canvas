# 开源协议

无限画布采用 GNU Affero General Public License v3.0（AGPL-3.0-only）开源协议。你可以在遵守协议要求的前提下使用、复制、修改、分发和商业运营本项目；修改后通过网络向用户提供服务时，必须按协议向这些用户提供当前运行版本的对应源代码。

## 项目初衷

无限画布保持开源，希望让更多人可以查看和修改代码，不被固定 API 渠道限制，接入自己的 API 与模型渠道，用画布组织提示词、参考图、素材和生成结果，搭建适合自己的 AI 创作工作流。

## 使用建议

如果你只是本地学习、研究或自用，可以直接按开源协议使用。

如果你计划将项目用于商业产品、私有化交付、SaaS 服务或长期团队内部系统，可以在完整遵守 AGPL-3.0 源码提供、版权声明和许可声明等要求的前提下使用、修改和分发。

如果你需要修改后闭源分发、闭源提供网络服务或获得其他许可条件，需要另行取得商业授权。

如果你需要私有化部署支持、定制开发服务，请查看[商务合作](/docs/business/business)。

## 源码获取

canvas.openai.fit 是本项目的修改版，按 AGPL-3.0 第 13 条向所有用户提供当前运行版本的对应源代码：

- 页面顶栏、画布工具栏和后台页头的「源代码」图标，首页和登录页底部的「源代码」链接，都指向本站的 `/source/`，即 https://canvas.openai.fit/source/。
- 源码包在发版时用 `git archive` 从发版提交打出，线上镜像用的就是这同一份源码；源码包文件名里带着对应的提交号。
- 上游基线、修改内容和修改日期见仓库根目录的 `MODIFICATIONS.md`。
- 3D 导演台（`web/public/director/`）目前只有构建产物，源码待上游作者提供后补进源码包，详见 `MODIFICATIONS.md`。
